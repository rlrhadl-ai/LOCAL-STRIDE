# AI 러닝 메이트

`/ai-mate`: 갈색 곰 보리와 다람쥐 다람 중 선택. 홈·마이·완주 결과·러닝 메뉴에서 진입한다. 두 캐릭터 모두 같은 분석과 추천을 제공하며 말투만 다르다.

## 기능과 데이터

- 캐릭터마다 3열 × 2행 투명 이미지: 기본, 생각, 말하기 닫힌 입, 말하기 열린 입, 환호, 휴식. 로딩·응답·컨디션·피드백에 따라 전환한다. 듣기 버튼을 눌러야 음성이 재생되며 기기의 한국어 TTS를 사용한다. 동작 줄이기 설정을 존중한다.
- 실제 LIVE, 검증된 완주, 최근 28일만 분석한다. 기존 API의 최대 30회 제한이 있다. 대표 페이스는 시간/거리 중앙값이다. 같은 코스·비슷한 거리의 과거 기록이 2개 이상일 때 마지막 러닝과 비교한다. GPS 구간 분석이나 체력·부상을 추정하지 않는다.
- 목표·시간·컨디션·지역·테마·피드백으로 공개 코스를 최대 3개 선정한다. 시간은 이동·휴식 제외 러닝 시간이다. 적합한 코스가 없으면 빈 상태로 안내한다.
- 캐릭터·취향·피드백은 사용자 ID별로 이 기기에 저장한다. 다른 기기로 동기화되지 않는다. 컨디션은 한국 날짜 변경 시 기본값으로 돌아간다. 대화는 메모리에만 보관하고 화면 이탈 또는 지우기 시 삭제한다.

## 서버와 AI

기존 AWS API와 데이터베이스는 변경하지 않는다. Vercel의 `POST /api/mate-chat`가 서버 전용 `API_ORIGIN`으로 `/me`, `/me/runs`, `/courses`, `/weather/now`를 조회한다. 기존 로그인 쿠키와 기기 ID는 이 지정된 서버에만 전달한다. 클라이언트가 보내는 사용자 ID·기록 요약·외부 URL을 신뢰하지 않는다.

생성형 대화는 로그인한 사용자에게 제공한다. AI SDK 7, Node.js 22 이상이 필요하다. Vercel 프로젝트 OIDC 또는 로컬의 비공개 `AI_GATEWAY_API_KEY`로 인증한다. `AI_GATEWAY_MODEL`로 모델을 변경할 수 있으며 기본값 `anthropic/claude-haiku-5.5`는 2026-11-09 실시간 목록에서 확인했다. 출력 최대 600토큰, 재시도 없음, 모델 제한 시간 16초다.

Gateway 팀 인증·결제수단 확인·잔액·예산은 운영자가 활성화해야 한다. 자동 결제나 예산 변경은 하지 않는다. 키 누락·모델 오류·타임아웃은 `source: RULE`로 기록 안내를 반환하고 UI에 구분한다. 익명 이용자는 기록 안내·캐릭터·코스 추천을 이용할 수 있다.

AI에는 질문/최근 대화, 계산된 러닝 요약, 컨디션, 공개 코스 정보만 전달한다. GPS 궤적, 정확한 활동 시각, 사용자 ID, 이메일, 닉네임, 쿠키는 전달하지 않는다. 원본 질문이나 인증 정보를 로그에 남기지 않으며 외부 상태를 변경하는 AI 도구도 없다.

본문·히스토리 길이와 사용자별 프로세스 내 분당 6회 제한이 있다. 여러 인스턴스에 걸친 전역 제한은 아니므로 서비스 규모 확대 시 프로젝트 지출 제한과 분산 요청 제한을 함께 설정한다.

## 검증 및 배포

`web`에서 `npm ci`, `npm run test:mate`, `npm run typecheck`, `npm run build`. 개발 서버는 `API_ORIGIN=<기존 API 주소>`, `NEXT_PUBLIC_API_URL=/`. 기존 GitHub의 main과 연결된 Vercel 자동 배포를 유지한다.

2026-11-09 로컬 검증: 분석·추천 단위 검사 14개, 형식 검사, 프로덕션 빌드 통과. 기존 AWS API에 연결한 대화 요청은 익명 기록 안내 200, 잘못된 캐릭터 400, 다른 출처 요청 403, 기기 ID 없는 요청 401을 확인했다. 모바일에서 두 캐릭터 이미지·휴식 표정·선택 복원·대화 표시와 가로 넘침 없음까지 확인했다. 로그인한 사용자의 생성형 응답과 배포 상태는 운영 계정 연결 후 별도 검증이 필요하다.

`public/images/mates/*-states.png`는 내장 이미지 생성 도구로 생성한 투명 원본이다. CSS로 6칸을 표시하고 Next.js가 전송 이미지를 최적화한다. 최종 프롬프트는 `ai-mate-image-prompts.json`에 기록한다.
