    DATA TRANSPARENCY

    이 데모가 사용하는 데이터

    관광지 · 장소 (TourAPI 형식)반경 500m 추천 장소는 한국관광공사 TourAPI 4.0 locationBasedList 응답 형식(contentid·contenttypeid·title·addr1·mapx·mapy·dist)으로 저장한 데모 데이터입니다. 실제 서비스는 API 실시간 호출로 대체됩니다.
    대구 관광코스 36건수성못의 주소·수변 데크·둘레 약 2km·야경 설명을 코스 테마와 음성 안내 문구에 사용했습니다.
    수성구 자전거도로 73건수성못길·무학로·들안로의 노선 길이와 도로 유형을 러닝 후보 구간 구성에 참고했습니다.
    수성구 체육시설 615건수성랜드 인근 체육시설을 운동 거점 체크포인트 후보로 활용했습니다.
    지도Leaflet + OpenStreetMap/CARTO 타일. 오프라인이면 같은 좌표로 그린 벡터 지도로 자동 전환됩니다.
    날씨 · 일몰기상청·AirKorea 연동 전 저장된 시연값입니다.
    데이터의 한계
    지도 위 경로·체크포인트 좌표·120m 반경·완주 시간은 데모용 시연값입니다. 출시 전 실제 GPX 제작·현장 답사·GPS 오차·횡단·야간 조도 검증이 필요하며, 쿠폰은 제휴 전 가상 혜택입니다.
